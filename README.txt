AI寺子屋 スマホ・PC両対応版 v1.2

構成:
- v1.2 = 「今日の一言」・朗読・生活への接続、AI教師の生き方教育要素を追加した確認用再構築版
- index.html = トップページ
- start/index.html = 始めるページ（スマホのローカル保存でも開きやすい構成）
- start.html = 直接開く場合・Web公開時の互換用

利用手順:
- 初回のみ：開始用プロンプトをコピー → ChatGPTで新しいチャットに貼り付け → 年齢を入力して授業開始
- 2日目以降：前回使った同じChatGPTのチャットを開き、「今日の寺子屋を始めよう」と入力するだけ
- 毎日プロンプトをコピーする必要はありません

リンク:
- トップ上段「AI寺子屋を始める」→ #start
- 中段・下段・フッター「AI寺子屋を始める」→ start/index.html
- 始めるページ → ../index.html

スマホでZIPを解凍して index.html を開く場合、ファイル管理アプリによっては兄弟ファイルへのリンクが制限されることがあります。
そのため中段・下段のリンクは start/index.html へ接続しています。
PWAとして使用する場合はHTTPSで公開してください。
