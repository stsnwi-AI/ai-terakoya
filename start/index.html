保護者の方へ

大切なのは、利用者に「正解」を言わせることではありません。

AI寺子屋では、考える → 話す → 別の視点を知る → もう一度考える → 実践するという経験を積みます。

✓ 1回10分程度
✓ 年齢・学習経験に合わせて対話
✓ AIの答えを鵜呑みにしない
✓ 毎回、現実の生活で一つ実践
