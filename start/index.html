STEP 1

AI寺子屋のプロンプトをコピー

下の文章をすべてコピーしてください。この文章が、ChatGPTを「AI寺子屋の先生」として動かすための指示になります。

この操作は初回だけです。
2日目以降は、このプロンプトを毎日コピーする必要はありません。前回使った同じChatGPTのチャットを開き、「今日の寺子屋を始めよう」と入力してください。
STEP 2｜初回のみ

初回はChatGPTで授業を始める

新しいチャットを開いて、さきほどコピーしたプロンプトを貼り付け、送信します。AI教師から年齢を聞かれたら年齢を入力してください。

ChatGPTを開く ↗

※ChatGPT側で新しいチャットを開いてください。貼り付けたら、そのまま送信します。

STEP 3｜初回のみ

AI教師に「年齢」を伝える

初回のプロンプトを送信すると、AI教師が年齢を聞きます。年齢を伝えると、その日の授業が始まります。

例

「30歳です」

名前・住所・勤務先などは入力する必要はありません。年齢だけで大丈夫です。

STEP 4｜2日目以降

毎日の授業は、同じチャットから続けます

初回は年齢を伝えると、AI教師が現在の日付と曜日、52週カリキュラムに合わせて授業を始めます。

2日目からは、プロンプトをコピーし直す必要はありません。
前回の授業で使った同じChatGPTのチャットを開き、「今日の寺子屋を始めよう」と入力してください。前回までの会話を踏まえて、次の授業へ進みます。

授業は約10分

今日のテーマ → 問い → 利用者の答え → 「なぜ？」 → 別の視点 → 今日の実践

答えは一つではありません

「分からない」「そう思わない」という答えも大丈夫。自分の理由を考えることを大切にします。

保護者の方へ

大切なのは、利用者に「正解」を言わせることではありません。

AI寺子屋では、考える → 話す → 別の視点を知る → もう一度考える → 実践するという経験を積みます。

未成年者が利用する場合は、保護者の方も、すぐに答えを教える代わりに「どうしてそう思ったの？」と聞いてみてください。

✓ AIの答えを鵜呑みにしない
✓ 毎回、現実の生活で一つ実践
